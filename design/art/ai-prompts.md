# Grimoire Haven — AI Art Prompt Book

Dark fantasy bullet-haven. Art direction: Hades / Cult of the Lamb, toon shaded, dark fantasy.

## How to use this

Generate each batch as **ONE contact sheet image**, then slice it into individual files.
A generation model holds style far better *inside* a single image than across many separate
generations — one sheet means one lighting pass, one outline weight, one palette temperature
for the whole batch. Slicing a consistent sheet beats regenerating icons one by one and
praying they match.

Workflow per batch:

1. Compose a single generation request using the batch's contact-sheet layout suggestion.
2. Generate, review at both full size and 40 px (most icons render at ~40 px in-game).
3. Slice the sheet into the individual files listed in each batch table.
4. Drop the files into the project (see the final checklist) using the **exact filenames**.

## The locked style suffix

> **WARNING: append this VERBATIM to the end of every single prompt. Never paraphrase it,
> never reorder it, never "improve" it. It is the style contract for the whole game.**

```text
dark fantasy game asset, toon shaded, thick uniform black outline, flat cel shading with only two tone steps, limited palette, strong rim light from upper left, bold readable silhouette, centered, no text, no watermark, no border frame, transparent background, painterly-graphic hybrid in the style of Hades and Cult of the Lamb
```

Every prompt in this document already ends with the suffix. If you write a new prompt,
copy the suffix from the code block above.

## Build order — and why

Generate the batches **in this order**:

1. **Batch 1 — Main Menu.** The menu plates decide the whole look. The backdrop and wordmark
   are the largest, most-seen pieces of art in the game; every later batch is judged against
   them. Lock the style here first.
2. **Batch 2 — Shared UI Chrome.** Panels, buttons, sliders and toggles are reused on every
   screen (settings, codex, shop, tooltip). Getting the chrome right once means every screen
   inherits it for free.
3. **Batch 3 — The Grimoire Board.** The board sets the *value range* of the whole UI: it is
   deliberately low contrast so everything placed on it reads as brighter. If the board is too
   loud, no icon on top of it can win.
4. **Batch 4 — Runes.** Runes are the BASE layer under skills: dark, calm, carved stone and
   inked page, low contrast on purpose. They must exist before skills so the skills can be
   tuned to sit on top of them and still dominate.
5. **Batch 5 — Sigils** and **Batch 6 — Status/Buff icons.** Small symbolic layers that live
   between the runes and the skills.
6. **Batches 7–10 — Skills** (Fire, Ice, Lightning, Arcane). Skills come LAST: bright, high
   contrast, sharp silhouettes. Only after the dark base layers exist can you verify a skill
   icon out-shines everything beneath it.

The rule underneath the order: **dark and quiet first, bright and loud last** — each layer is
calibrated against the layer below it.
